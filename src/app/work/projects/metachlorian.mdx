## Finding the shot

I wanted to be able to ask for a shot I remembered without having to remember the filename. Metachlorian indexes a library of footage so an editor can search for what appears on screen or what somebody said. The result takes you to the moment in the source.

## Back into the edit

The desktop app lets you select clips and send them to an editor. An API and MCP server expose the same library to other tools. For stills, the photo workflow can shortlist images and edit virtual copies in Lightroom Classic.
