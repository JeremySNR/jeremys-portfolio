## A first mod you can actually play

Start with a free Luanti world. Pick a recipe, change how high a character jumps or how gravity feels, and launch the game to try it. On Windows, the app can set up the game itself.

## Room to experiment

Each project gets an isolated world. Codex CLI can help author or revise recipes, and recovery tools give you a way back if an experiment breaks. Sharing the recipe lets another player try the same change.

[Read the getting-started guide](https://github.com/JeremySNR/Modalore/blob/main/docs/GETTING_STARTED.md)
